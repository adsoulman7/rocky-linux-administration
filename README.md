#Rocky Linux Software Update 

## Objective :
Learn how to check for and install software updates on Rocky Linux

## Environment
- Operating System: Rocky Linux
- Virtualization: Oracle VirtualBox
- Task: Software package management
## Command 1: Software Update 
sudo dnf update 

### What this command does ?
sudo : Runs a command with administrator privileges.
dnf :  Linux package manger
update: Checks configured repositories and updates installed packages to the latest available  versions.
